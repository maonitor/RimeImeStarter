Third-party native libraries shipped in this APK
================================================

These binaries are prebuilt with the Android NDK and loaded at runtime by
libimebridge.so via dlopen("librime.so"). They are NOT linked at compile time.

librime.so (3.6 MB, arm64-v8a)
  Upstream : https://github.com/rime/librime  tag 1.12.0
  License  : BSD 3-Clause (see app/src/main/cpp/third_party/LICENSE)
  Exports  : rime_get_api / rime_get_api_stdbool / RimeRegisterModule / RimeFindModule
  Statically linked into librime.so:
    - yaml-cpp 0.8.0        https://github.com/jbeder/yaml-cpp       (MIT)
    - leveldb 1.23          https://github.com/google/leveldb        (BSD-3-Clause)
    - marisa-trie (rime fork) https://github.com/rime/marisa-trie     (BSD-style)
    - OpenCC (master)       https://github.com/BYVoid/OpenCC         (Apache-2.0)
    - Boost 1.84.0 headers + Boost.Regex
                            https://www.boost.org                    (BSL-1.0)
  License texts of the statically linked components are available from the
  upstream repositories above; consult them before redistributing.

libc++_shared.so (1.8 MB, arm64-v8a)
  Source   : Android NDK 27.0.12077973
  License  : Apache-2.0 WITH LLVM-exception
  Required because librime.so was built with -DANDROID_STL=c++_shared.
  AGP does not analyze dependencies of prebuilt jniLibs, so it is shipped
  explicitly (scripts/build-librime-android.sh copies it from the NDK).

Reproduce / rebuild
-------------------
  ./scripts/build-librime-android.sh <ANDROID_NDK_HOME> arm64-v8a
  ./scripts/verify-rime-so.sh

Only arm64-v8a is shipped. On other ABIs the app degrades gracefully to
MockPinyinEngine (the candidate bar shows "mock" instead of "rime <version>").
